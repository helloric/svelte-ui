# The +page.svelte

The actual "displaying" happens inside the `+page.svelte` file inside the _routes_ folder. The `+page.svelte` can be seen as the homepage or main page of a website. If our web application contained different subpages, they would be listed here in the _routes_ folder too. Because we just swap the face components in and out based on the current emotion, we only need one index page, saving us the trouble of creating multiple subpages for each emotion. 

## The content

First, we import the necessary stuff for the display to function properly. Next, two arrays, one for the allowed emotions and one for the allowed colors, are declared. Lastly, the current emotion in the array is set.
